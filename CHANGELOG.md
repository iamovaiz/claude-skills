# Changelog

## v1.0.0 (2026-11-21)

First public release, five skills:

- **post-check**: pre-publish check for LinkedIn and X posts, with your own off-limits list
- **zkteco-attendance-import**: ZKTeco First & Last exports to a monthly attendance grid, with lowest-cost shift pairing that handles night shifts
- **staged-release-supabase-vercel**: staging-first release procedure, plus `served_version.py` to prove the live domain serves the new build
- **supabase-vercel-ops-checks**: setup and health checklist for Supabase and Vercel apps
- **project-board-sync**: read the project board before work, suggest evidence-backed updates after

Each skill is attached below as a zip for upload to Claude apps.
